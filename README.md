# Photoshop-Auto-Replace-Texts-Image-Layers
A simple tool for Adobe Photoshop that batch-replaces texts, image layers from CSV data, saving hours of manual layout work I have spent for 2 years without creating this after a 2000 VIP guests event lol.

---

## ✨ Features

- **Automated Text & Image Replacement:** Swaps out text content and Smart Object / image layers directly from CSV columns.
- **Image Placement Modes:** Choose between **Fill**, **Fit**, or **Stretch** for automated image sizing.
- **Flexible Export Formats:** Export directly to **PNG**, **JPEG**, **PSD**, or **TIFF**.
- **Layer Export Control:** Options to flatten or export a single merged layer while preserving the main file.
- **Dynamic File Naming:** Define custom output naming rules using CSV column variables (e.g., `[DocName]_[Name]_[ID].png`).
- **Minimal UI:** Built with an intuitive ScriptUI dialog interface.

## 🚀 Installation
### 1. Download the Script:
Download the latest CSV_Auto_Replace.jsx file from the Releases page.

### 2. Copy to Photoshop Scripts Folder:
Place the .jsx file into your Photoshop installation directory:

Windows: C:\Program Files\Adobe\Adobe Photoshop [Version]\Presets\Scripts\

macOS: /Applications/Adobe Photoshop [Version]/Presets/Scripts/

### 3. Restart Photoshop:
Once installed, access the script in Photoshop from File > Scripts > CSV_Auto_Replace.

### Note:
Alternatively, you can run the script without moving it by opening Photoshop and navigating to File > Scripts > Browse... and selecting CSV_Auto_Replace.jsx.
